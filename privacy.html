Privacy policy

Last updated 4 October 2026

This policy covers the Grid Puzzle Walkthroughs YouTube channel, this website, and Puzzle Walkthroughs Uploader (“the Uploader”), the channel's own software for uploading its videos.

YouTube API Services

The Uploader uses YouTube API Services. By using the Uploader you agree to be bound by the YouTube Terms of Service. Information handled through YouTube is also covered by the Google Privacy Policy.

Who uses the Uploader

The Uploader is used only by the channel's owner, on the owner's own computer, to manage the channel's own videos. It is not offered to the public, and no one else signs in to it.

What the Uploader accesses

When the channel's owner signs in with Google, the Uploader is given permission to manage that YouTube channel. It uses that permission only to:

  • upload the channel's walkthrough videos, and set their titles, descriptions, thumbnails and privacy setting;
  • create the channel's playlists (one per puzzle) and change which video each holds;
  • read the channel's ID and name, and the details of the channel's own videos and playlists, to check that each upload went to the right channel and finished correctly.

It does not access, collect or store any information about viewers, subscribers, commenters or any other YouTube user.

What is stored, and where

  • The sign-in token that lets the Uploader act for the channel is stored only on the owner's computer. It is never sent anywhere except to Google when the Uploader talks to YouTube.
  • A record of the channel's uploads: for each puzzle, the IDs of its video and playlist, and when it was uploaded. This is stored only on the owner's computer and is used only to keep each playlist pointing at the right video.

Nothing is stored on any server of ours. No information obtained through YouTube API Services is sold, shared with or disclosed to anyone else.

Cookies

The Uploader is a desktop program and places no cookies on anyone's device. This website sets no cookies and uses no analytics or advertising. It is hosted by GitHub Pages, which may record technical information such as IP addresses for security purposes; see the GitHub Privacy Statement.

Watching our videos

Watching our videos on YouTube is covered by YouTube's own terms and the Google Privacy Policy. The channel sees only the standard, aggregated statistics YouTube gives every channel.

Revoking access and deleting data

Anyone who has signed in to the Uploader can revoke its access at any time on Google's security settings page: security.google.com/settings/security/permissions. When access is revoked, the stored sign-in token stops working; it and the upload records are deleted from the owner's computer within 7 days.

Changes

If this policy changes, the new version will be posted on this page with a new date.

Contact

Questions about this policy can be raised on this website's GitHub page.
